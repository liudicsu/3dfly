3 · How to record & serve locally

# A) Record from a live stream
python scripts/stream_client.py --url ws://localhost:8765 --seconds 20 \
  --dump output/ui_verify/pr6/live_frames.bin

# B) Or record while simulating (no client required)
threedfly run-interactive --stream-port 8765 --stream-record output/demo.bin …

# C) Replay through the server (websocket fan-out)
python scripts/stream_replay.py output/ui_verify/pr2/live_frames.bin --port 8767 --hz 10
#    → http://localhost:8767/demo
#    → http://localhost:8767/brain?rec=/recording.bin

# D) Or plain static tree (assets + panel; use file picker for the .bin)
python -m http.server 8971 --directory .
#    → http://localhost:8971/threedfly/stream/static/demo.html

Do not publish this page to GitHub Pages — assets and recordings are for local verification only.
